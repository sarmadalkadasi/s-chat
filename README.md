# S Chat 💬🔒

A modern, fast, cross-platform chat application built with **Flutter** and powered by **Supabase**. Features End-to-End Encryption (E2EE) for 1-to-1 direct messages and group chats, sticky date headers, offline-first persistence, voice notes, rich media attachments, and group management.

## 🌟 Key Features

- **🔐 End-to-End Encryption (E2EE)**:
  - **Direct Messages (1-to-1)**: X25519 ECDH key exchange + AES-256-GCM encryption.
  - **Group Chats**: Signal Protocol Group Sender Keys architecture.
  - Private keys remain on device inside secure hardware storage.

- **💬 Telegram/WhatsApp-Styled Chat & Groups List (`ChatList`)**:
  - Real-time list of available user conversations and group chats.
  - Live search filtering by user/group name or last message snippet.
  - Circular profile avatars with online status indicators and fallback initials.
  - Formatted timestamps ("10:45 AM", "Yesterday", "Mon") and unread message counter badges.

- **📌 Sticky Headers & List Dividers**:
  - Date dividers ("Today", "Yesterday", "Mon, Oct 14") stick at the top of the chat view while scrolling.
  - "Not Read Messages" divider banner separating read and unread messages.

- **👥 Full Group Management**:
  - Create new groups with custom group names and avatars picked via `UserImagePicker`.
  - Group Owner settings screen (`GroupSettingsScreen`) to edit Group Name, upload Group Avatar, toggle Private/Public group status, and add members.
  - Owner-gated actions and group deletion workflow.

- **⚡ Offline-First Architecture**:
  - Instant 0ms UI render powered by local disk caching.
  - Offline outbox queue automatically retries sending messages and attachments when internet connection is restored.

- **🎙️ Rich Media Messaging**:
  - Voice notes recorder and player.
  - Photo and document attachments via Supabase Storage.
  - Markdown-style formatted text renderer and context menu.

- **🌐 Cross-Platform**:
  - Flutter Web (Chrome), Android, iOS, Windows, macOS, and Linux.

## 🛠️ Supabase Setup & Database Schema

To set up your Supabase project, execute the following SQL scripts in your **Supabase Dashboard -> SQL Editor**:

```sql
-- 1. Users Table
create table if not exists public.users (
  id text primary key,
  username text not null default 'Anonymous',
  image_url text default '',
  public_key text default '',
  created_at timestamptz default now()
);

-- 2. Chat Messages Table
create table if not exists public.chat_messages (
  id bigint generated by default as identity primary key,
  user_id text not null,
  text text not null default '',
  iv text default null,
  username text default 'Anonymous',
  user_image text default '',
  chat_id text default null,
  recipient_id text default null,
  created_at timestamptz default now(),
  reply_to_id text default null,
  reply_to_username text default null,
  reply_to_text text default null
);

-- Index for fast message sorting
create index if not exists idx_chat_messages_created_at 
on public.chat_messages (created_at desc);

-- 3. Groups Table
create table if not exists public.groups (
  id text primary key,
  name text not null,
  image_url text default '',
  created_by text not null,
  is_private boolean default false,
  created_at timestamptz default now()
);

-- 4. Group Members Table
create table if not exists public.group_members (
  id bigint generated by default as identity primary key,
  group_id text not null references public.groups(id) on delete cascade,
  user_id text not null,
  role text default 'member',
  joined_at timestamptz default now(),
  unique(group_id, user_id)
);

-- 5. Group Sender Keys Table (Signal Protocol)
create table if not exists public.group_sender_keys (
  id bigint generated by default as identity primary key,
  group_id text not null references public.groups(id) on delete cascade,
  sender_id text not null,
  recipient_id text not null,
  encrypted_key text not null,
  iv text not null,
  created_at timestamptz default now(),
  unique(group_id, sender_id, recipient_id)
);

-- 6. Enable Realtime Sync
alter publication supabase_realtime add table chat_messages;
alter publication supabase_realtime add table groups;
alter publication supabase_realtime add table group_members;
alter publication supabase_realtime add table group_sender_keys;

-- 7. Disable RLS or configure public access rules
alter table public.users disable row level security;
alter table public.chat_messages disable row level security;
alter table public.groups disable row level security;
alter table public.group_members disable row level security;
alter table public.group_sender_keys disable row level security;
```

### Storage Buckets Setup
In **Supabase Dashboard -> Storage**, ensure the following buckets exist:
1. **`chat-media`**: Bucket for chat attachments, voice recordings, and files.
2. **`user_images`** (Public): Bucket for user profile pictures and group avatars.

## 🚀 Getting Started & Build Instructions

### Prerequisites
- Flutter SDK `^3.11.4` or newer.
- Dart SDK `^3.11.4`.

### Installation
```bash
# 1. Clone the repository
git clone https://github.com/your-username/s_chat.git
cd s_chat

# 2. Get dependencies
flutter pub get

# 3. Run unit tests
flutter test

# 4. Run static analysis
flutter analyze
```

### Running the App
```bash
# Run on Web (Chrome)
flutter run -d chrome

# Run on Android / iOS
flutter run

# Run with environment variables (Optional)
flutter run --dart-define=SUPABASE_URL=https://your-supabase-url.supabase.co --dart-define=SUPABASE_ANON_KEY=your-anon-key
```
